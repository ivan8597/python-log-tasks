# Python log tasks

Учебные решения задач по анализу логов:

- `count_success_and_failure` — считает успешные и неуспешные автопродления;
- `auto_renewal_sub` — считает накопительное среднее и медиану количества пользователей с автопродлением;
- `sub_renewal_by_day` — считает успешные продления по дням недели.

## Кейс campaign_data.csv

Файл `campaign_tasks.py` содержит решения всех заданий кейса по рекламным кампаниям:

- средняя конверсия по платформе, типу кампании и городу;
- доли рекламных затрат по платформам и городам;
- средний бюджет по платформе;
- генератор пропущенных дат запуска кампаний;
- группировка бюджета и кликов по городам;
- генератор кампаний по городу и минимальному бюджету.

Установка зависимости:

```bash
pip install -r requirements.txt
```

Запуск:

```bash
python campaign_tasks.py campaign_data.csv
```

Функции находятся в `log_tasks.py` и `campaign_tasks.py`.
