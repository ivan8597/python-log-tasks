# Python log tasks

Учебные решения задач по анализу логов:

- `count_success_and_failure` — считает успешные и неуспешные автопродления;
- `auto_renewal_sub` — считает накопительное среднее и медиану количества пользователей с автопродлением;
- `sub_renewal_by_day` — считает успешные продления по дням недели.

Все функции находятся в `log_tasks.py`.
